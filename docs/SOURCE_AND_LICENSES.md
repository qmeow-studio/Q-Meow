本倉庫用作 Q-Meow 的公開下載、使用文件及問題追蹤。目前尚未提供公開 Beta APK。

GitHub 為本倉庫 Release 自動產生的 `Source code (zip)`／`Source code (tar.gz)`，只包含本倉庫的文件及設定，**不是 Android app 的完整原始碼**。

「免費試用」描述下載及使用安排，不表示所有程式碼、字典、圖像及第三方元件都採用相同授權。

開發基準已包含 Apache-2.0 授權文字及第三方 NOTICE。正式發布每個 Beta 前，需保留 APK 內適用的授權／版權告示，核對字典、資源及依賴套件的再分發要求，並在 Release 附上對應告示。若有元件需要提供相應原始碼，亦需按其適用條件提供。

此文件不對尚未完成檢查的內容作統一授權聲明。日後若公開完整 app 原始碼，會另列實際位置、版本及適用授權。
