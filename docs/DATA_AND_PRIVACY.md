# 資料處理與公開回報

這份說明供 Beta 測試者了解主要資料路線。首個公開 APK 發布前，需要按實際版本完成核對，並在 Release 註明適用版本。

## 語音輸入

鍵盤內語音會呼叫手機選用的語音辨識服務。語音服務可能使用網絡；音訊及辨識資料的處理亦受該服務商的設定及私隱政策影響。

「在鍵盤內辨識」不等於「所有音訊一定只在手機處理」。離線辨識是否可用，要視乎引擎及已備妥的語言模型。

## 翻譯

- **離線翻譯**：需要先準備所需模型；模型下載需要網絡。模型備妥後，相關翻譯可以在手機上處理。
- **網上翻譯**：使用者要求翻譯的文字會送交選用的翻譯服務。Beta 需核對在線開關、同意提示及失敗路線，避免在說明中把網上服務稱為完全離線。

請勿使用尚未完成驗證的 Beta 翻譯敏感資料。

## 剪貼簿及設定

剪貼簿與設定備份可能包含私人文字。舊開發版本的設定匯出可包含完整偏好設定，包括使用者填入的翻譯 API key。

因此，**請不要把設定匯出檔、剪貼簿記錄或整份手機備份貼到公開 Issues**。這些內容不屬於一般問題回報所需資料。

## 分享診斷記錄

公開 Issues、留言及上載的附件都可能被其他人閱讀。分享前請刪除或遮蓋：

- 實際輸入／辨識文字、私人訊息及帳戶資料。
- 姓名、電話、電郵、地址及可識別個人的截圖內容。
- API key、密碼、token、設定備份及簽署私鑰。

一般回報只需版本、手機型號、Android 版本、錯誤碼、所選語言／引擎及重現步驟。使用沒有私人資料的短句重現即可，不需要錄音或完整對話。

本倉庫的問題表格只會在你提交時公開你填入的內容；請自行檢查附件與文字。
