# 已知問題與測試狀態

更新日期：2026-10-30。**本公開倉庫目前未發布 Beta APK。**

以下資料是首發準備狀態，不是對所有手機的相容性承諾。實際發布時，每個 Release 需要另列該 APK 的實機結果。

## 已確認的開發測試結果

- 開發測試中，使用者曾確認鍵盤內粵語辨識可以出字。
- 這項結果不代表目前所有語言、手機、辨識引擎及長文流程均已通過。

## 首發前仍待確認

- 全新安裝，以及由既有測試版覆蓋更新。
- 倉頡、速成、筆劃、注音、英文及符號輸入。
- 粵語、普通話、英文辨識；長文、取消、收起鍵盤及切換 app／輸入欄位。
- 語音沒有文字時的重試上限，以及重試後會否重複輸入或寫入另一欄位。
- 網上翻譯失敗時的離線路線、未下載模型時的提示及取消行為。
- 小螢幕、橫向畫面、字型放大及不同 Android 品牌的顯示／操作。

## 尚待解決的發布檢查

在已檢查的開發基準中，語音主回歸測試仍採用較早的「聽到聲但沒有文字就停止」預期，與後來加入的有限重試政策衝突。需要更新測試以驗證已決定的行為並通過檢查，才能當作首發門檻已完成。

不能把「APK 編譯成功」等同「所有回歸及實機測試通過」。

## 每個版本應如何標示

- **已修復**：列明問題、修正及驗證環境；程式碼改完但未實機確認，要註明範圍。
- **仍待測試**：列出具體測試與尚欠的手機／語言／操作情境。
- **尚未解決**：記錄症狀、暫時做法及相應 Issue。

首個 Beta 發布時，會在 [Releases](https://github.com/terence19770217-ctrl/Q-Meow/releases) 補上版本、附件與已測試裝置。
