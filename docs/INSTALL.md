# 安裝及更新 Q-Meow

目前公開 Beta 尚在準備；下列步驟供 APK 發布後使用。

## 下載及安裝

1. 開啟 [Q-Meow Releases](https://github.com/terence19770217-ctrl/Q-Meow/releases)，選擇希望測試的 Beta。
2. 閱讀該版本的「已知問題」及「已測試環境」。
3. 在 **Assets** 下載檔名以 `.apk` 結尾的檔案。
4. 開啟下載檔案。如 Android 要求允許該瀏覽器／檔案管理員安裝應用程式，按手機提供的設定處理；安裝後可關閉該來源的安裝權限。
5. 開啟 Q-Meow，按設定頁提示啟用鍵盤，再從手機的輸入法選擇器切換至 Q-Meow。

不同品牌手機的設定名稱可能不同。請保留原有可用的輸入法，方便測試期間切換。

`Source code (zip)`、`Source code (tar.gz)` 及 `.aab` 不是本指引使用的直接安裝 APK。

## 使用語音

- 在普通文字欄位開啟 Q-Meow，按鍵盤的咪掣。
- 首次使用時允許 Q-Meow 的咪高峰權限，選擇需要的語言再說一句。
- 語音在鍵盤內進行；公開 Beta 的驗收要求不包含自動切換至外部 Google 語音視窗。
- 引擎可用性取決於手機已安裝、已啟用的辨識服務及其語言支援。出錯時請記錄畫面錯誤碼；單看「有聆聽畫面」不能判斷辨識成功。

## 更新

從同一個官方 Release 頁下載較新版本的 APK，直接覆蓋安裝。發布流程會核對套件名稱、簽署憑證及遞增的 versionCode；安裝後請確認設定及常用輸入法仍正常。

遇到更新失敗，請先提供目前與新 APK 的版本、完整安裝錯誤及手機型號。不要先解除安裝或清除資料，以免失去設定及個人詞彙。

## 常見問題

| 情況 | 先檢查 |
| --- | --- |
| APK 無法開啟 | 是否下載完整的 `.apk`，而非 ZIP／AAB；與該版列出的 Android／CPU 支援是否相符 |
| 覆蓋安裝失敗 | 現有版本、簽署來源及完整錯誤訊息 |
| 已安裝但找不到鍵盤 | 手機設定中是否已啟用 Q-Meow，並已切換目前輸入法 |
| 鍵盤沒有彈出 | 換一個普通文字欄位測試，記下發生的 app 及重現步驟 |
| 語音有畫面但沒有字 | 記錄語言、長文開關、錯誤碼及診斷中的選用引擎；回報前刪除私人內容 |
